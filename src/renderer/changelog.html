JTech Browser

Version 0.7.0

Fixes

  • Bang commands (!yt, !g, !gh, custom bangs) now work in the address bar, not only on the new tab page.
  • Loading an extension from a file (.crx/.zip/folder) no longer fails and is saved correctly.
  • Bookmark folders can be deleted again.
  • Density buttons in settings no longer trigger a stale tab layout save.

Version 0.6.0

Highlights

  • Custom cursor selectable from preset styles.
  • Reworked background particles: elegant, modern bokeh drift.
  • JTech Bangs: create and manage custom bang commands in settings.
  • Custom cursor image support in the theme editor.
  • JTech CS bang commands (!yt, !yt-d, !g, !ddg, !gh, !github).
  • Omnibox suggestions from open tabs, bookmarks and history.
  • Media keyboard shortcuts: Space/K play-pause, Up/Down volume, M mute, P pause all.
  • Settings persistence hardened (atomic writes, corrupt-file backup).
  • Per-tab volume control with live sync to the actual video volume.
  • Volume boost up to 300% for quiet videos (Web Audio gain).
  • Media Hub with playback cards, seek, mute and play/pause.
  • Keyboard shortcuts for media: Space/K play-pause, Up/Down volume, M mute, P pause all.
  • Vertical tabs, tab groups, favorites, split view, session restore.
  • Theme editor with cursor effects and 12 presets.
  • Adblocker, command palette, extensions support.
