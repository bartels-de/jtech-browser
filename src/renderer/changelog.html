JTech Browser

Version 0.8.0

Design Studio

  • Completely redesigned Design Studio with live preview, preset gallery and saved themes.
  • Eight new animated backgrounds: Network, Synthwave, Flow, Hyperdrive, Hex grid, Nebula, Ribbons and Embers, each with a live preview.
  • Eleven new presets, including the new default Nova and two light themes (Paper, Daylight).
  • Fewer controls on the main tabs; fine-tuning moved to Advanced.
  • Animations pause in gaming mode and in background tabs.
  • Note: your theme is reset to Nova once and old saved themes are removed. Custom CSS is kept.

Extensions

  • Real extension popups with Chrome extension APIs (chrome.tabs, chrome.action, context menus).
  • Extension icons and badges in the extensions menu.
  • Warning when an extension needs APIs the browser cannot provide (for example uBlock Origin Lite).
  • Reinstalling an extension now updates it instead of reporting an error.

Resources

  • New resources panel (Shift+Esc) with live CPU and RAM charts and a process manager.
  • CPU limit (hard on Windows), RAM limit that puts background tabs to sleep, and a low priority mode for gaming.

Updates

  • Automatic updates from GitHub Releases: downloaded in the background, installed on the next restart or with one click.

Performance

  • Browsing history is stored in its own file and saved in batches instead of rewriting all settings on every page load.

Fixes

  • Bang commands (!yt, !g, !gh, custom bangs) now work in the address bar, not only on the new tab page.
  • Loading an extension from a file (.crx/.zip/folder) no longer fails and is saved correctly.
  • Bookmark folders can be deleted again.
  • Sleeping tabs in gaming mode no longer disappear from the tab list.
  • Quitting with sleeping tabs no longer crashes.
  • Density buttons in settings no longer trigger a stale tab layout save.

Version 0.6.0

Highlights

  • Custom cursor selectable from preset styles.
  • Reworked background particles: elegant, modern bokeh drift.
  • JTech Bangs: create and manage custom bang commands in settings.
  • Custom cursor image support in the theme editor.
  • JTech CS bang commands (!yt, !yt-d, !g, !ddg, !gh, !github).
  • Omnibox suggestions from open tabs, bookmarks and history.
  • Media keyboard shortcuts: Space/K play-pause, Up/Down volume, M mute, P pause all.
  • Settings persistence hardened (atomic writes, corrupt-file backup).
  • Per-tab volume control with live sync to the actual video volume.
  • Volume boost up to 300% for quiet videos (Web Audio gain).
  • Media Hub with playback cards, seek, mute and play/pause.
  • Keyboard shortcuts for media: Space/K play-pause, Up/Down volume, M mute, P pause all.
  • Vertical tabs, tab groups, favorites, split view, session restore.
  • Theme editor with cursor effects and 12 presets.
  • Adblocker, command palette, extensions support.
